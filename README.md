# CALM

CALM is a macOS workspace built around a nearly infinite canvas. You draw rectangles and get
live terminals (Ghostty), browser panels (WebKit) and plugin panels (HTML/JS) that you can
move, resize, pan and zoom around like a whiteboard. It is written in Rust on GPUI.

Status: prototype in progress. Nothing here is released.
